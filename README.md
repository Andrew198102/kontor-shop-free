# Kontor Shop (Free)

Vereinsshop für WordPress: Artikel mit Varianten, Lager, Vorkasse, Abholung und Kassier-Ablauf.

- **Installieren:** unter [Tags](../../tags) das ZIP der neuesten Version laden, in WordPress unter *Plugins → Plugin hinzufügen → Plugin hochladen*.
- **Updates:** diese Ausgabe aktualisiert sich selbst von hier – mit *Automatische Aktualisierungen aktivieren* in der Plugin-Liste ganz von allein.
- **Pro:** über *Kontor Shop → Upgrade* im Plugin, siehe [veyra-assistant.com/kontor-shop](https://veyra-assistant.com/kontor-shop/).

Dieses Repository wird bei jedem Release automatisch befüllt; Änderungen hier gehen beim nächsten Release verloren.
